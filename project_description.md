# Описание проекта

## 1. Название системы

**«Электронная библиотека»** — онлайн-сервис для поиска книг, ведения списка чтения и отзывов.

## 2. Назначение системы

Сервис помогает читателю:

- найти книгу;
- сохранить её в личный список;
- отмечать прочитанное;
- делиться отзывами;
- получать рекомендации по своей истории чтения.

Каталог пополняют сами пользователи, в том числе через импорт из Google Books. Администратор следит за качеством данных и отзывов.

## 3. Пользователи и роли

| Роль | Описание |
|---|---|
| **Гость** | Незарегистрированный посетитель. Смотрит каталог, карточки книг и отзывы, ищет книги, может зарегистрироваться. |
| **Читатель** | Зарегистрированный пользователь. Ведёт «Избранное» и отмечает прочитанное, ставит оценки и пишет отзывы, получает AI-рекомендации, добавляет в каталог книги, которых там нет. |
| **Администратор** | Владелец сервиса. Исправляет и удаляет книги, авторов, жанры и категории, удаляет недопустимые отзывы, блокирует нарушителей, следит за работой сервисов. |

## 4. Основные бизнес-процессы

1. **Регистрация и вход.** Гость регистрируется и получает роль «Читатель». При входе система выдаёт токен доступа и продлевает его без повторного ввода пароля.
2. **Поиск книги.** Гость или Читатель ищет книгу по названию, фильтрует по автору, категории и году и открывает карточку книги с описанием, отзывами и рейтингом.
3. **Ведение списка чтения.** Читатель добавляет книгу в «Избранное», отмечает её прочитанной, удаляет из списка. По этому списку AI-модуль подбирает рекомендации.
4. **Отзывы и оценки.** Читатель ставит книге оценку от 1 до 5 и пишет отзыв. Из оценок складывается рейтинг книги. Администратор удаляет отзывы, нарушающие правила.
5. **Пополнение каталога.** Читатель не нашёл книгу, ищет её в Google Books и добавляет в каталог. Администратор исправляет ошибки и удаляет дубли.

## 5. Функциональные требования

| № | Требование | Приоритет |
|---|---|---|
| 1 | Гость может зарегистрироваться по логину, email и паролю. Логин и email уникальны. | Must Have |
| 2 | Читатель может войти и получить токен доступа. При истечении токена он продлевается без повторного ввода пароля. | Must Have |
| 3 | Гость и Читатель могут искать книги по названию и фильтровать по автору, категории и году издания. Вывод постраничный, до 20 книг на страницу. | Must Have |
| 4 | Гость и Читатель могут открыть карточку книги: название, автор, год издания, описание, жанры и отзывы. | Must Have |
| 5 | Читатель может добавить книгу в «Избранное» одним нажатием из карточки и удалить её оттуда. Повторное добавление одной и той же книги не допускается. | Must Have |
| 6 | Читатель может отметить книгу в «Избранном» как прочитанную. | Must Have |
| 7 | Система поддерживает разграничение доступа: Гость только просматривает, Читатель добавляет, Администратор редактирует и удаляет. | Must Have |
| 8 | Читатель может поставить книге оценку от 1 до 5 и написать отзыв. Не больше одного отзыва на книгу. | Should Have |
| 9 | Читатель может найти книгу в Google Books и добавить её в каталог, если её там нет. | Should Have |
| 10 | Администратор может редактировать и удалять книги, авторов, жанры и категории. | Should Have |
| 11 | Администратор может удалять отзывы и блокировать пользователей. | Should Have |
| 12 | Читатель получает до 5 рекомендаций книг из каталога по его прочитанным книгам, с пояснением к каждой. | Should Have |
| 13 | Читатель может сменить пароль в личном кабинете. | Should Have |
| 14 | Читатель получает отчёт о чтении: сколько книг в «Избранном», сколько прочитано, любимые жанры. | Nice to Have |
| 15 | Администратор получает отчёт по каталогу: топ-10 книг по рейтингу и по числу добавлений в «Избранное». | Nice to Have |

## 6. Технологический стек

### СУБД
- PostgreSQL 16;
- миграции схемы — Alembic.

### Backend
- Python 3.11, FastAPI, Uvicorn;
- ORM — SQLAlchemy 2.0 (асинхронный режим, драйвер asyncpg);
- валидация данных — Pydantic 2;
- аутентификация — JWT (python-jose);
- хеширование паролей — bcrypt (passlib);
- HTTP-клиент для внешних API — httpx;
- тесты — pytest.

### Frontend
- React 18, сборщик Vite;
- маршрутизация — React Router 6;
- запросы к API — Axios;
- PWA (service worker, manifest);
- тесты — Vitest и React Testing Library;
- ESLint, Prettier.

### AI-модуль
- Ollama с локальной моделью `qwen2.5:3b` для рекомендаций книг.

### Внешние API
- Google Books API для поиска и импорта книг.

### Инфраструктура
- Docker, Docker Compose (конфигурации для разработки и продакшена);
- Nginx как шлюз и раздача статики фронтенда.
