# Нефункциональные требования

### Производительность
- **Количество одновременных пользователей:** 1
- **Допустимое время отклика:** не более 1 секунды

### Безопасность
- **Аутентификация:** требуется.
- **Разграничение прав доступа:** требуется.

### Надёжность
- **Допустимое время простоя:** SLA отсутствует
- **Резервное копирование (бэкап):** требуется

### Масштабируемость
- **Планируемый рост нагрузки:** не планируется

# Границы системы

### In Scope (входит в систему)
- Пользователи и авторизация
- Учёт книг
- Поиск книг
- Избранное
- Написание отзыва, выставление оценки

### Out of Scope (не входит в систему)
- Google Books API
- модель рекомендаций

### Внешние системы для интеграции
- Google Books API
